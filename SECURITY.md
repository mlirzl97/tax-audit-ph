# Security policy

Do not report vulnerabilities in public issues. Until a dedicated security
address is published, contact the project maintainer privately through the
repository owner's verified channel.

Never include real notices, TINs, names, addresses, tax amounts, credentials,
access tokens, or client documents in a report. Use fabricated examples.

The initial supported deployment is a dedicated Frappe site for one firm or a
single-user evaluation site. A shared hosted consumer deployment is not
approved until row-level tenant isolation, malware scanning, file retention,
backup encryption, and breach-response procedures pass security review.
